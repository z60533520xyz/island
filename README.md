# 🏝️ 卡坦島 Online

這是卡坦島（Catan）基本版的網頁實作。開一個房間、把連結傳給朋友就能開始玩，玩家之間透過 **WebRTC 點對點連線**，不需要架設遊戲伺服器。

## 快速開始

```bash
npm start          # 等同 node serve.mjs 8080，不需要安裝任何套件
# 開啟 http://localhost:8080/
```

ES module 不能直接用 `file://` 開啟，所以需要一個靜態伺服器。要讓不同電腦的朋友加入，把整個資料夾部署到任何靜態網站空間就行（GitHub Pages、Netlify、Cloudflare Pages…），**一定要用 HTTPS**，因為瀏覽器只允許在安全來源上使用 WebRTC。

1. 輸入名字 →「建立新房間」，會拿到一組 5 碼的房間代碼與邀請連結
2. 朋友開啟邀請連結（或輸入代碼）→ 加入
3. 2~6 人到齊後，房主按「開始遊戲」。2~4 人使用基本地圖，5~6 人會自動改用擴充大地圖

### 房間設定（房主在大廳設定）

| 設定 | 說明 |
|---|---|
| 隨機座位順序 | 預設開啟：開始時打亂玩家順序，決定誰先開始與回合順序（顏色也跟著順序分配） |
| 準備階段每輪放置道路 | 預設 1 條（官方規則）；可以改成 2 條（家規），第 2 條必須接在本輪的村莊或第 1 條道路上 |
| 特別建設階段 | 只適用於 5~6 人，預設開啟（官方擴充規則） |

在同一台電腦上測試：開**另一個視窗**（不要直接複製分頁，複製分頁會沿用同一個玩家身分），貼上邀請連結即可。

## 架構

```
index.html        畫面骨架（首頁 / 大廳 / 遊戲）
css/style.css
js/geometry.js    棋盤幾何（基本 19 塊／擴充 30 塊）與隨機版圖產生
js/engine.js      規則引擎：純資料、沒有 DOM 依賴，可以在 Node 裡測試
js/net.js         PeerJS 包裝：HostNet / ClientNet
js/ui.js          SVG 棋盤與側邊欄的渲染、按鈕事件
js/main.js        房主／客戶端的訊息處理、畫面切換、斷線重連
serve.mjs         本機開發用的靜態伺服器
test/             自動化測試
```

**房主權威（host-authoritative）**：規則引擎只在房主的瀏覽器上執行。
- 客戶端 → 房主：`{t:'hello', name, token}`、`{t:'action', action}`、`{t:'chat', text}`
- 房主 → 客戶端：`{t:'lobby'}`、`{t:'state', view}`、`{t:'error'}`、`{t:'chat'}`、`{t:'kick'}`

每位玩家收到的 `view` 都經過 `viewFor()` 處理：資源卡是公開資訊，所有人都看得到；其他人的發展卡只會顯示張數，牌庫順序也不會傳出去，所以沒辦法透過開發者工具偷看別人的發展卡。

連線使用 [PeerJS](https://peerjs.com/) 的免費公共配對伺服器（`0.peerjs.com`）交換連線資訊，建立連線後資料直接在瀏覽器之間傳送。

## 已實作的規則

- 隨機版圖（6 和 8 不會相鄰）；基本地圖有 9 個港口（4 個 3:1、5 個 2:1）
- 準備階段採蛇形順序，第二座村莊會立即產出資源
- 擲骰產出資源；銀行庫存不足時依官方規則處理
- 擲出 7：手牌超過 7 張的玩家棄掉一半 → 移動強盜 → 搶奪（家規：資源卡公開，強盜自選對象並指定搶走哪種資源；官方規則是隨機抽一張）
- 建造道路、村莊、城市，並檢查距離規則與連接規則
- 發展卡（基本版：騎士 14、分數 5、道路建設 2、豐收之年 2、壟斷 2）：每回合限用一張，當回合買的卡不能使用
- 最長道路：至少 5 段，會被其他玩家的村莊截斷，平手時由原持有者保留
- 最大騎士團：至少 3 位騎士
- 交易：銀行 4:1、港口 3:1 或 2:1；也可以向所有玩家提出交易，由提案者挑選一位接受的玩家成交
- 回合分為交易階段與建設階段：一旦建造或購買發展卡，本回合就不能再交易，未成交的提案自動取消（道路建設卡的免費道路不算）
- 在自己的回合達到 10 分就獲勝（隱藏的分數卡也會自動計入）

### 5~6 人擴充

- 30 塊地形的大地圖，每列 3-4-5-6-5-4-3，有 2 個沙漠、28 個數字、11 個港口（5 個 3:1；羊毛 2:1 有兩個）
- 銀行每種資源 24 張；發展卡 34 張（騎士 20、分數 5、道路建設／豐收之年／壟斷各 3）
- 特別建設階段：每個回合結束後，其他玩家從下一位開始依序可以建造或購買發展卡，不能交易，也不能使用發展卡

## 斷線與恢復

- **客戶端**重新整理或斷線後，會用同一個分頁的身分（存在 sessionStorage）自動回到原本的座位
- **房主**每次狀態改變都會存進 localStorage；如果房主關掉頁面，重新開啟首頁可以按「恢復上次的對局」，用同一組房間代碼重新開房，其他玩家重新連線即可接著玩
- 如果有玩家離線卡住遊戲（輪到他、或他需要棄牌），房主可以按「代為行動」自動完成目前的步驟

## 限制

- 房主離線時遊戲會暫停，直到房主恢復房間
- 部分企業網路或對稱式 NAT 環境沒辦法直接建立 P2P 連線。遇到這種情況需要在 `js/net.js` 的 `iceServers` 加入 TURN 伺服器
- 沒有實作航海家、城市與騎士等其他擴充版

## 測試

```bash
npm test
```

- `test/simulate.mjs`：用隨機機器人跑 300 局 2~6 人的完整對局，每一步都檢查資源總數守恆與棋子數量，並驗證非法動作會被拒絕、隱藏資訊、最長道路被截斷的情況
- `test/render.mjs`：用簡化的 DOM 替身，在 3 人與 6 人的各種遊戲狀態與對話框下執行所有渲染路徑
- `node test/snapshot.mjs 6 board.svg`：輸出一張隨機棋盤的 SVG，方便目視檢查
